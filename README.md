## 📌 Sobre esta versión

Sentía que mi portafolio anterior se había quedado atrás y ya no mostraba mi nivel técnico actual. Decidí rehacerlo desde cero para enfocarlo hacia el rumbo profesional al que quiero llevar mi carrera.

Esta **versión 2.0** representa un salto cuantitativo y cualitativo en mi perfil como **Desarrollador Web Frontend**. He diseñado una experiencia limpia, en **modo oscuro (Dark Mode)**, priorizando el rendimiento, la usabilidad (UX/UI) y la escalabilidad del código.

### 🌟 Principales Novedades

- 🛠️ **Stack Frontend Moderno:** Desarrollada con **React 19**, **Tailwind CSS v4** y **Vite**, combinando la lógica de estado con un diseño moderno y mantenible. Desplegado en **Vercel**.
- 📚 **Nueva Etapa Académica:** Inicio del **Grado en Ingeniería Informática** (UOC, 2026) para complementar mi trayectoria profesional y mi título en DAW, profundizando en arquitectura de software y diseño de sistemas escalables desde la base.
- ✒️ **Experiencia de Usuario (UX/UI):** Interfaz refinada en modo oscuro, micro-interacciones fluidas, filtrado dinámico de proyectos y diseño completamente _responsive_.

## 🛠️ Instalación y Uso Local

Si deseas clonar y explorar este portafolio localmente:

```bash
# 1. Clonar el repositorio
git clone https://github.com/LuisChicaizaDev/portafolio-v2.git

# 2. Acceder al directorio
cd portafolio-v2

# 3. Instalar dependencias
npm install

# 4. Iniciar el servidor de desarrollo
npm run dev
```

La aplicación se abrirá en `http://localhost:5173/`.
